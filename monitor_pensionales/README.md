# Monitor Pensionales

- `Ejemplo_Monitor_Pensionales_Dinamico.xlsx`: libro Excel dinámico con datos sintéticos (composición, estrategia, riesgo y activos comunes). Abrir en Excel de escritorio; las instrucciones están en la hoja `09_INSTRUCCIONES`.
- `Vista_previa_dashboard.png`: imagen del dashboard.
- `generador/`: scripts de Python (openpyxl) que construyen el libro. Uso: `python build.py salida.xlsx 5000`.
